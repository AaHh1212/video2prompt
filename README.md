# موقع تحويل الفيديو إلى برومبت

موقع محلي (تفتحه من متصفحك) بترفع فيه فيديو أو تحط رابط، ويحلل الفيديو
ويطلع لك برومبت تفصيلي مقسّم مشهد بمشهد (Image Prompt + Video Prompt)
تقدر تستخدمه في Google Flow / Veo لإنتاج فيديو مشابه.

## المتطلبات
- Python 3.9+
- ffmpeg مثبت على جهازك:
  - ماك: `brew install ffmpeg`
  - لينكس (أوبنتو): `sudo apt install ffmpeg`
  - ويندوز: نزّل من ffmpeg.org وضيفه للـ PATH
- مفتاح Anthropic API (من console.anthropic.com)

## التثبيت والتشغيل

```bash
cd video2prompt
pip install -r requirements.txt
export ANTHROPIC_API_KEY="sk-ant-..."   # على ويندوز: set ANTHROPIC_API_KEY=sk-ant-...
python app.py
```

بعدها افتح المتصفح على:
```
http://127.0.0.1:5000
```

هتلاقي واجهة فيها تابين: "رفع فيديو" و"رابط فيديو"، اختار الطريقة اللي تناسبك،
حدد عدد المشاهد اللي تبيها (6 افتراضي)، واضغط "حلل الفيديو وطلع البرومبت".

## ملاحظات مهمة

- **الروابط**: الموقع يستخدم مكتبة `yt-dlp` عشان يحمل الفيديو من يوتيوب/تيكتوك/
  انستغرام أو أي رابط مباشر. بعض المنصات ممكن تمنع التحميل أو تحتاج تسجيل دخول،
  في هالحالة الأسهل ترفع الفيديو مباشرة من جهازك بدل الرابط.
- **الفيديوهات الطويلة**: كل ما زودت عدد الفريمات كل ما زاد التحليل دقة، بس
  زاد وقت المعالجة وتكلفة الـ API. لفيديو 30 ثانية، 6 فريمات كافية عادةً.
- **النشر أونلاين**: هذا السيرفر مضبوط للتشغيل المحلي (`debug=True`). لو تبي
  تنشره على الإنترنت (مثلاً على Render أو Railway) خبرني وأضبطلك الإعدادات
  المناسبة للإنتاج (production) + طريقة رفع الكود.
- **حقوق النشر**: لو الفيديو الأصلي مش ملكك، استخدم البرومبت الناتج كإلهام
  وتطوير على أسلوبك الخاص، مش كنسخ حرفي لمحتوى شخص تاني.

## النشر أونلاين من الجوال (بدون كمبيوتر) — رابط عام

تقدر تسوي كل هذا من متصفح الجوال، بدون تثبيت أي برنامج:

### الخطوة 1: ارفع الملفات على GitHub
1. اعمل حساب على github.com (لو ما عندك).
2. اضغط "+" فوق > "New repository"، سمّيه مثلاً `video2prompt`، خليه Public، واضغط Create.
3. جوا الريبو اضغط "Add file" > "Create new file".
4. في خانة اسم الملف اكتب: `app.py` — والصق فيه محتوى ملف app.py اللي عندك، وسوي Commit.
5. كرر نفس الخطوة لباقي الملفات:
   - `requirements.txt`
   - `Dockerfile`
   - `Procfile`
   - `templates/index.html` ← **مهم:** اكتب المسار كامل بالخانة (يعني `templates/index.html`) وGitHub بيسوي المجلد تلقائي.

### الخطوة 2: استضف على Render
1. روح render.com واعمل حساب (تقدر تسجل بحساب GitHub مباشرة).
2. اضغط "New +" > "Web Service".
3. اختار الريبو `video2prompt` اللي رفعته.
4. Render بيكتشف الـ Dockerfile تلقائيًا (Environment: Docker) — سيبها كذا عشان ffmpeg يتثبت صح.
5. تحت "Environment Variables" ضيف:
   - Key: `ANTHROPIC_API_KEY`
   - Value: مفتاحك (sk-ant-...)
6. اضغط "Create Web Service" وانتظر يخلص البناء (Build) — ياخذ كم دقيقة.
7. بعد ما يخلص، بيديك رابط زي:
   `https://video2prompt-xxxx.onrender.com`

هذا الرابط هو موقعك العام — تفتحه من أي جهاز وتستخدمه.

**ملاحظة:** الخطة المجانية في Render بتنام (sleep) لو ما حد يستخدم الموقع لفترة، وأول طلب بعد النوم ياخذ نص دقيقة تقريبًا يصحّي. طبيعي.
